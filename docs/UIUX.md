# UI/UX 가이드

이 앱의 UI/UX 철학과 구체 지침. 모든 화면·컴포넌트 작업 시 이 문서를 따른다.

## 한 줄 목표

**사용성 우선 + 부드러운 UX.** 토스처럼 — 군더더기는 없지만 차갑지 않고, 흐름이 매끄럽고 손에 붙는 느낌.

> 판단 기준: "멋있나?"가 아니라 **"쓰기 쉬운가? 흐름이 매끄럽고 기분 좋은가?"**

## 두 축의 균형 (중요)

딱딱함과 화려함 사이를 잡는다.

- **너무 딱딱(X)**: 모션 0, 직각·무미건조, 시스템 기본 alert 남발 → 쓸 수는 있지만 불쾌하고 싸구려 느낌.
- **너무 화려(X)**: 과한 그라데이션·글로우, 의미 없는 장식 애니메이션 → 도구 앱엔 부담, 느려 보임.
- **우리(O)**: 정보는 깔끔하게 정리하되, **전환·피드백을 부드럽게** 해서 흐름이 끊기지 않게. 장식이 아니라 "흐름"에 공을 들인다.

## 모션 & 인터랙션 (토스의 결)

모션은 장식이 아니라 **상태 변화를 이해시키고 흐름을 잇는 도구**다.

- **의미 있는 전환에 모션을 쓴다**: 화면 전환, 바텀시트 슬라이드업, 모드 전환(Viewer↔Edit), 도형 선택, 검색 결과 등장. 갑자기 튀지 않고 자연스럽게 이어지게.
- **부드러운 커브**: 선형(linear) 말고 ease-out 계열로 감속감 있게. reanimated 의 spring/timing 을 적절히. 너무 통통 튀지 않게, 차분하면서 부드럽게.
- **빠르고 가볍게**: 전환은 짧게(대략 150~300ms 체감). 느린 모션은 답답하다. 부드러움 ≠ 느림.
- **즉각적 피드백**: 누르면 바로 반응(press 시 살짝 눌리거나 옅게 하이라이트). 탭했는데 아무 반응 없는 순간을 없앤다.
- **상태는 부드럽게 이어준다**: 로딩→완료, 빈 목록→채워짐 등은 갑자기 바뀌지 말고 fade/slide 로 전환. 레이아웃이 튀지 않게.
- **햅틱**: 중요한 확정 동작(저장, 삭제 확정, 모드 전환)에 가벼운 진동을 더하면 손맛이 산다(expo-haptics, 절제해서).

## 시각 스타일

- **둥근 모서리·여백으로 부드럽게**: 직각보다 적당한 라운드, 답답하지 않은 여백. 토큰(@shared/theme)의 radius/spacing 사용.
- **깊이는 은은하게**: 과한 그림자 대신 옅고 부드러운 그림자나 연한 음영으로 카드·시트를 띄운다.
- **강조색은 핵심 동작에**: 주요 액션·선택·포커스에 브랜드 색을 쓰고, 나머지는 중립으로 차분하게. 색을 흩뿌리지 않되, 무채색만으로 차갑게 만들지도 않는다.
- **도형 색·자재 사진이 주인공**: UI 크롬은 한 발 물러나 콘텐츠가 돋보이게.
- **타이포 위계**: 제목/본문/보조의 크기·굵기 차이를 명확히 해서 한눈에 읽히게. 토큰을 따른다.

## 사용성 (마찰 제거 — 토스의 본질)

부드러움의 핵심은 결국 **할 일을 쉽게, 적은 단계로** 하게 만드는 것이다.

- **흐름을 짧게**: 주요 동작(편집 진입, 도형 추가, 자재 추가, 검색)은 한두 탭으로 도달. 불필요한 단계·확인을 줄인다.
- **한 화면 한 초점**: 화면마다 핵심 동작이 분명하게 보인다. 기능을 욱여넣지 않는다.
- **터치 타겟 넉넉히**: 최소 44dp. 작은 버튼/핸들로 누르기 어렵게 만들지 않는다(현장에서 빠르게 조작).
- **파괴적 동작은 부드럽게 보호**: 삭제 등은 확인하되, 차가운 시스템 alert보다 앱 톤에 맞는 바텀시트/다이얼로그로. 가능하면 되돌리기(undo) 토스트를 고려.
- **빈 상태·로딩·에러를 친절하게**: 빈 화면 방치 금지. 부드러운 안내 문구 + 다음 행동 유도(예: "첫 평면도를 만들어보세요" + 버튼). 로딩은 skeleton 으로 자연스럽게.
- **입력은 편하게**: 자재 이름(필수) 등 입력은 키보드 흐름·자동 포커스·적절한 키패드로 마찰을 줄인다.

## 일관성

- **같은 동작은 같은 자리·같은 모양**: 화면마다 버튼 위치·모션·컴포넌트가 흔들리지 않는다.
- **공용 컴포넌트로 통일**: 버튼·시트·카드·입력은 shared 컴포넌트를 재사용해 모션·스타일을 한 곳에서 관리(@shared/theme + shared/components).
- **모션도 일관되게**: 전환 길이·커브를 토큰/공용 유틸로 통일해 앱 전체가 같은 리듬으로 움직이게.

## 빠르게 보는 체크리스트

- [ ] 탭/전환에 부드러운 모션이 있고, 누르면 즉시 피드백이 오는가
- [ ] 모션이 짧고 가벼운가(답답하지 않은가)
- [ ] 주요 동작이 한두 탭 안에 있는가
- [ ] 빈 상태/로딩/에러가 친절하게 처리됐는가
- [ ] 색·여백·라운드·모션이 토큰 기준으로 화면 간 일관적인가
- [ ] 차갑게 딱딱하지도, 과하게 화려하지도 않은가
